# 🧪 스마트 스터디 랩 (Smart Science Study Lab)

> **환경화학 · 농업생태학 · 생물통계학 · 생명과학 전공자를 위한 실전문항 풀이 & 핵심 개념 아카이브**  
> 🔗 **배포 웹사이트**: [https://bi0philia.github.io/knou/](https://bi0philia.github.io/knou/)

---

## 🌟 주요 기능

### 1. 📝 실전 문제 풀이 시스템 (총 415문항 탑재)
- **과목별 학습**:
  - 🧪 **환경화학** (65문항): **[기초 핵심 1~6강 특화]** + **[심화 종합 7~15강]** 단계별 문항
  - 🌾 **환경친화형농업** (70문항): 친환경 인증, IPM, 토양생태 실전문항
  - 📊 **생물통계학** (70문항): 가설검정, ANOVA, 상관/회귀 계산 풀이
  - 🧬 **생물과학** (70문항): 세포 소기관, 광합성, 유전 중심원리
  - 🌿 **식물분류학** (70문항): 식물계통, 형태학, 주요 과별 식별키
  - 🔬 **환경미생물학** (70문항): 미생물 생장, 활성슬러지, 생물정화
- **2가지 학습 모드**:
  - **즉시 학습 모드**: 문항을 풀자마자 정답(O/X)과 상세 해설, 관련 개념 태그를 즉시 확인
  - **실전 테스트 모드**: 25분 타이머 작동, OMR 마킹 시각화, 문항 번호판, 최종 채점 리포트 및 폭죽 효과
- **특화 기능**:
  - 무작위 문제 셔플 기능
  - 수식 및 화학 반응식 KaTeX 렌더링 지원 ($PV=nRT$, $\text{pH}$, 화학식 등)
  - 도표 및 화학 구조 이미지 탭 확대/축소 모달

### 2. 📚 과목별 핵심 개념 & 공식 아카이브
- **환경화학 기초 15대 테마 전수 족보**: 주기율표, 질량수, 분자식, 르샤틀리에, 화학평형, pH 등 빈출 테마 완전 정복
- **계산 공식 치트시트**: 몰수, 몰농도, 노르말농도, 이상기체 방정식, 람베르트-베르, 아레니우스 등 핵심 공식 원터치 복사
- **전 과목 핵심 요약**: 6개 전 과목 요점 정리 및 실시간 검색 필터

### 3. ⭐ 오답노트 & 북마크
- 내가 틀린 문제 자동 누적 기록
- 별표(★) 북마크로 중요 문항 보관
- `선택 항목 모아 풀기` 기능으로 취약점 집중 복습
- 모바일 브라우저 `localStorage`에 자동 영구 저장

### 4. 📱 모바일 퍼스트(Mobile-First) UX
- 한 손 엄지손가락으로 편하게 누를 수 있는 대형 보기 버튼 (최소 52px)
- iOS Safari 및 안드로이드 하단 Safe Area Inset 완벽 대응
- 다크 모드 / 라이트 모드 지원
- 글자 크기 3단계 조절 (A- / A+)
- 오프라인-퍼스트 번들 탑재 (`data/bundle.js`)로 네트워크 지연 없는 즉각 로딩

## 🚀 GitHub Pages 배포 설정 방법

본 프로젝트는 순수 HTML5/CSS3/Vanilla JS로 구성되어 별도의 빌드 과정 없이 정적 웹 호스팅이 가능합니다.

1. GitHub 레포지토리 (`https://github.com/bi0philia/knou`) 방문
2. **Settings** -> 좌측 메뉴의 **Pages** 클릭
3. **Build and deployment** 항목:
   - **Source**: `Deploy from a branch` 선택
   - **Branch**: `main` 브랜치 / `/ (root)` 폴더 선택 후 **Save** 클릭
4. 약 1~2분 후 `https://bi0philia.github.io/knou/` 주소로 접속 가능합니다.
